# Biomappings SSSOM Export

The data is distributed under the
[Simple Standard for Sharing Ontology Mappings (SSSOM)](https://github.com/mapping-commons/sssom)
format. Each file is assigned a PURL in the
`https://w3id.org/biopragmatics/biomappings/sssom/` namespace.

> **Warning** The SSSOM export contains a combination of the manually curated
> positive mappings and predicted mappings. Please use the mapping justification
> and confidence accordingly. Note that prediction confidences are generated by
> each prediction script according to its own rules - some give a global
> confidence and some give a prediction-specific confidence.

| Facet        | Description                                | PURL                                                                    | Link                                                                                                                    |
| ------------ | ------------------------------------------ | ----------------------------------------------------------------------- |-------------------------------------------------------------------------------------------------------------------------|
| TSV          | Mappings (predicted and curated)           | https://w3id.org/biopragmatics/biomappings/sssom/biomappings.sssom.tsv  | [`export/biomappings.sssom.tsv`](https://github.com/biopragmatics/biomappings/raw/main/export/biomappings.sssom.tsv)    |
| Metadata YML | Metadata that go along with the TSV export | https://w3id.org/biopragmatics/biomappings/sssom/biomappings.sssom.yml  | [`export/biomappings.sssom.yml`](https://github.com/biopragmatics/biomappings/raw/main/export/biomappings.sssom.yml)    |
| JSON         | Mappings in JSON                           | https://w3id.org/biopragmatics/biomappings/sssom/biomappings.sssom.json | [`export/biomappings.sssom.json`](https://github.com/biopragmatics/biomappings/raw/main/export/biomappings.sssom.json)  |
| OWL          | Mappings in ontology format                | https://w3id.org/biopragmatics/biomappings/sssom/biomappings.sssom.owl  | [`export/biomappings.sssom.owl`](https://github.com/biopragmatics/biomappings/raw/main/export/biomappings.sssom.owl)    |
